# Contributing to Exti — Live Wallpaper Tab

Thank you for your interest in contributing to **Exti**! We welcome contributions from developers, designers, and enthusiasts.

---

## 🚀 How to Contribute

### 1. Reporting Bugs & Requesting Features
- Search existing GitHub Issues before opening a new one.
- If creating a bug report, include your browser name & version, OS, and steps to reproduce.

### 2. Local Development Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/4rmnd/exti-live-wallpaper-tab.git
   cd exti-live-wallpaper-tab
   ```
2. Open Chrome/Edge/Brave and navigate to `chrome://extensions/`.
3. Enable **Developer Mode**.
4. Click **Load Unpacked** and select the `exti/` directory.

### 3. Pull Request Guidelines
- Follow the existing Vanilla JS & CSS design system (no external heavy frameworks or dependencies).
- Ensure all code is formatted cleanly and adheres to Manifest V3 guidelines.
- Test changes in both 1080p and 1440p displays.
- Keep privacy first — no tracking, analytics, or external API calls without user consent.
